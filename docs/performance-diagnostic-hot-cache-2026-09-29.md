# FluxFeed Hot 候选缓存优化与正式分档记录

## 1. 结论

- P1 统一过滤后，Recommend 在 5 RPS 下延迟已达标，但 MySQL 连续四次采样为
  95.22%～106.91% CPU，超过 85% 资源红线，因此停止升压。
- 根因是 Hot 候选已经与用户无关，但每个 Recommend 仍对 10 万视频重新计算热度并排序。
- 增加 5 秒进程内 Hot 候选快照后，正式 5/10/20 RPS 分档全部通过，未出现推荐降级、
  HTTP 失败、业务失败、丢弃迭代或容器重启。
- 当前结果证明单机单 API 在 20 RPS Recommend 下通过最低红线；尚未完成连续三轮中位数、
  综合流量和 30 分钟稳定性测试，不能外推为最终容量上限。

## 3. 优化设计

Hot Source 先读取全局 200 条候选，用户的最近曝光、负反馈和屏蔽作者过滤发生在候选读取之后，
因此这 200 条原始候选可以安全地跨用户复用。本次在推荐 Service 内保存 5 秒不可变快照：

- 命中时复制候选对象，避免排序和打分修改缓存内容；
- 过期时只允许一个请求回源，其余请求等待同一次重建，避免缓存击穿；
- 数据库错误不写入缓存；
- 用户过滤、Interest/Similar 个性化和最终排序保持原语义；
- 不引入新依赖、Redis Key 或物化表。

5 秒 TTL 是当前单 API 架构下的最小实现。多 API 副本导致重复重建重新成为主要负载时，再将
候选快照迁移到 Redis；当前不提前增加分布式失效协议。

## 4. Before/After：5 RPS × 5 分钟

| 指标 | 缓存前 | 缓存后 | 变化 |
| --- | ---: | ---: | ---: |
| Recommend P95 | 267.58 ms | 62.42 ms | -76.7% |
| Recommend P99 | 300.16 ms | 206.21 ms | -31.3% |
| 最大响应时间 | 337.15 ms | 275.91 ms | -18.2% |
| 业务成功率 | 100% | 100% | 持平 |
| fallback / circuit / bulkhead / partial | 0 / 0 / 0 / 0 | 0 / 0 / 0 / 0 | 持平 |
| MySQL CPU 采样中位数 | 约 101.24% | 约 24.46% | -75.8% |
| MySQL CPU 采样峰值 | 106.91% | 32.65% | -69.5% |
| MySQL Queries/s 近似值 | 约 241 | 约 227 | -5.8% |

Queries/s 降幅小于 CPU 降幅，说明收益来自消除昂贵的全表计算排序，而不是隐藏或跳过用户级
过滤查询。

## 5. 优化后正式分档

| RPS | 请求数 | P95 | P99 | API CPU 采样峰值 | MySQL CPU 采样峰值 | 结果 |
| ---: | ---: | ---: | ---: | ---: | ---: | --- |

三个档位均满足：

- HTTP 失败率 0%，业务成功率 100%；
- `dropped_iterations=0`；
- fallback、circuit open、bulkhead full、partial recall 增量均为 0；
- 容器重启次数为 0；
- Outbox failed/pending 为 0，已发布事件数保持 19,875；
- MySQL `Slow_queries=0`，测试结束时 `Threads_running=2`。

20 RPS 最近 5 分钟的 Source P95：Hot 约 0.99 ms、Collaborative 约 23.06 ms、Following
约 9.22 ms、Interest 约 5.44 ms、Latest 约 4.94 ms、Similar 约 5.33 ms。

## 6. 判定与下一步

本批次完成了单次正式 5/10/20 RPS 分档。20 RPS 下 MySQL CPU 峰值已达到 79.40%，距离
85% 红线只剩约 5.6 个百分点，因此本轮不继续提高 Recommend RPS。

下一步按顺序执行：

1. 从 `medium-v1` 恢复相同快照，连续运行三次 20 RPS × 5 分钟并取中位数；
2. 三次均通过后运行综合 50 RPS × 15 分钟；
3. 综合场景通过后再执行 50 RPS × 30 分钟稳定性测试；
4. 多副本或更高 Recommend 流量确实使 5 秒重建成为瓶颈时，再评估 Redis 快照。
